# Base de conhecimento de marca

Um diretório por cliente, com o Guia de Identidade Visual extraído do Google Drive da Vanguarda Martech (texto fiel, sem resumo). Consumido pela ferramenta `brand_book_lookup` (src/marketing_ops/tools/brand_book.py).

Para adicionar um cliente: criar `knowledge/<slug>/` (slug em minúsculas, sem acentos, só a-z, 0-9 e _) com um ou mais arquivos `.md`; o cabeçalho YAML com `cliente:` é recomendado. Para atualizar, substituir o arquivo e republicar a branch de deploy.

Guias marcados como **incompletos** foram truncados pela API do Drive (arquivos grandes): a ferramenta avisa o agente e as decisões de marca desses clientes devem sair como [VALIDAR] até a versão completa ser carregada.
